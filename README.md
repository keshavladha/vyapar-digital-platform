## 🌟 Overview

**Vyapar Digital** is a digital craft studio built specifically for Indian local businesses, shopkeepers, institutes, and service providers. It empowers local entrepreneurs to establish a digital presence through custom websites, WhatsApp-integrated stores, Android apps, festive marketing posters, and viral reels.

## 🚀 Quick Start & Local Run

```bash
# Clone the repository
git clone https://github.com/keshavladha/vyapar-digital-platform.git

# Navigate to project directory
cd vyapar-digital-platform

# Serve locally
npx serve -l 3000 .
```

Visit `http://localhost:3000` in your browser.

---

## ☁️ Deploying to Vercel

This repository is pre-configured for **1-click Vercel deployment**:

1. Log in to [Vercel](https://vercel.com).
2. Click **"Add New Project"** and select **`vyapar-digital-platform`** from your GitHub account.
3. Keep default settings (`Framework Preset: Other` / Root directory: `./`).
4. Click **"Deploy"** — your platform will be live globally in seconds!
